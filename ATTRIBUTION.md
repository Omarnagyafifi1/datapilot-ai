Attribution and ownership for illustrations

The current isometric illustrations in `frontend/src/assets/illustrations/` are original artwork generated for this project. Filenames:

- `isometric-teal-data.svg` — generated in-house, teal isometric data scene.
- `isometric-neon-purple.svg` — generated in-house, neon purple isometric scene.
- `isometric-neutral-undraw.svg` — generated in-house, neutral isometric scene.

These illustrations were created and committed into the repository by the project maintainers and do not require external attribution. If you later replace any illustration with a third-party asset, update this file with the source URL, author, and license information.

Example entry format for third-party assets:

- `filename.svg` — "Title" by Author — Source URL — License (e.g., Free for commercial use, attribution required).
