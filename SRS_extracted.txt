4) Functional Requirements (FR)
FR
Name
Description
FR1
Upload CSV
User uploads a file; it is ingested and available as a
queryable table.
FR2
Connect
Database
User enters credentials; system tests and registers
the connection.
FR3
Retrieve Schema
System extracts tables + columns (and relationships
when available).
FR4
Context Filtering
System selects relevant tables/columns for the
question to reduce prompt size and improve accuracy.
FR5
Generate SQL
Produce SQL from the user question.
FR6
Optimize Query
Avoid full scans where possible; add LIMIT defaults;
prefer indexed filters when known.
FR7
Execute Query
Run SQL safely and return results with pagination
support.
FR8
Self-Healing
If execution fails, generate a fix and retry within safe
limits.
FR9
Generate
Insights
Analyze results and produce key findings.
